# Barcode Scanner Simulator

Учебный проект на Python, имитирующий работу сканера штрихкодов: обработку событий сканирования, их валидацию и сбор
статистики.

## 📋 О проекте

Проект создан в целях изучения Python. Он моделирует типичный pipeline обработки данных со сканера штрихкодов:

1. Данные о событиях сканирования загружаются из источника.
2. Каждое событие проходит валидацию.
3. Валидные события обрабатываются и агрегируются в статистику.
4. Результаты и сообщения об ошибках выводятся пользователю.

## ✨ Возможности

- Загрузка событий сканирования из файла/источника данных
- Валидация корректности событий (формат, обязательные поля и т.д.)
- Подсчёт статистики по обработанным событиям
- Понятный вывод сообщений о результатах работы и ошибках

## 🛠 Требования

- Python 3.8+
- pip

Полный список зависимостей — в [`requirements.txt`](./requirements.txt).

## 🚀 Установка и запуск

Проект использует виртуальное окружение `.venv`.

**1. Создать и активировать виртуальное окружение** (если ещё не создано):

```bash
python -m venv .venv
source .venv/bin/activate
```

**2. Установить зависимости:**

```bash
pip install -r requirements.txt
```

**3. Запустить проект:**

```bash
python main.py
```

**4. После завершения работы — деактивировать окружение:**

```bash
deactivate
```
